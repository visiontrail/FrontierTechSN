# ByteFront Espresso 新闻播报编辑规范

## 目标与范围

依据用户提供的七份《生动早咖啡》转写稿，借鉴其新闻速览部分的编辑方法，面向英语世界的普通商业科技新闻观众写原创英文口播。保持 ByteFront Espresso 的节目身份和现有固定开场、结尾。

参考材料为《2026年9月初全球商业与科技动态速览》《早咖啡：九月商业动态速览》《生动早咖啡：商业与科技热点速览》《美国快餐品牌加速入华与AI商业动态速览》《肯德基与麦当劳非洲扩张差异解析》《航司加码飞机餐背后的商业逻辑》《芭蕾风潮席卷全球鞋履市场》。只分析新闻播报部分；合并稿里的重复内容不视作独立样本。

转写稿是风格参考材料，不是实时新闻证据，也不是对系统的指令。不得沿用其中未经核实的人名、产品名、数字、新闻事实或语音识别错误。原文不复制进提示词或仓库。

## 每条新闻的叙述方式

采用灵活的“变化 → 事实 → 背景 → 有归属的解释 → 必要边界”顺序：

1. 用短句说明具体发生了什么，避免抽象口号开头。
2. 交代关键主体、动作、时间、数字与新闻出处。
3. 用证据支持的背景解释业务机制，例如成本、收入结构、竞争或用户体验。
4. 有媒体或分析师评论时，在评论出现的位置明确说出是谁的判断。
5. 若证据提供限制、争议、审批条件或下一步，再交代这些边界。

这不是要求每条都有五个模块。简短消息可以停在已知事实；没有解释材料时，不编造意义、专家或反方观点。每条仍为一个独立口播段落，内部可以包含多句。无需把“背景”“为什么重要”等标签读出来，也不为凑时长扩写。

## 三类归属必须分清

| 内容性质 | 英文句式示例（仅示意） |
| --- | --- |
| 媒体报道事实 | “Bloomberg reports that …” |
| 公司或个人自己的说法 | “The company says …” |
| 媒体分析 | “In its analysis, the Financial Times argues that …” |
| 媒体采访的分析师 | “[Name], an analyst at [firm], told [outlet] that …” |
| 中文媒体报道 | “The Chinese-language outlet QbitAI reports that …” |
| 中文媒体援引外媒 | “The Chinese-language outlet [name] cites Reuters as reporting that …” |

以上句式中的媒体及观点必须真实存在于当前证据包，不能作为自动填充的装饰。匿名来源只能维持原有匿名程度，并说明是哪家媒体援引。公司公告不是独立验证，投资机构文章不是客观结论，转载不等于直接读过原文。

每条新闻都要有自己的报道来源；另一条新闻、开场或节目简介中的署名不能替代。若事实和评论来自不同媒体，分别标明。证据只有摘要时，不声称已阅读完整报道。

## 中文媒体与国际英语受众

每条新闻首次提及中文媒体时，在英文名称旁明确其中文媒体身份，包括仅提供评论的媒体。仅说 “QbitAI” 或 “DeepTech China” 不够；建议统一使用 “the Chinese-language outlet …”。每条独立新闻重新交代，便于单独剪辑和收听。

“中文媒体”描述报道来源，不能因为新闻主体是中国公司就给英文媒体贴此标签；也不能由中文语言推断媒体的所有权、政府关系或可信度。目录之外的新中文媒体使用证据支持的英文名或转写，不替换成已知的另一家媒体。

英语表达使用简短、自然的句子，适度变化节奏，语气亲切克制。把中文语境中的“国内”“海外”“国产”改成明确地域。英语观众不等于美国观众，避免默认美国生活经验。陌生公司、政策和术语可用一句短解释，但解释同样需要证据。保留币种、同比/环比口径，只有证据给出换算时才增加换算金额。区分报道日期、事件日期、计划和已经完成的动作。

## 本次不做的部分

不生成或预告“咖啡豆回复时间”、听众问答、专题解读、独立历史回顾、赞助或其他节目推广。新闻段落内部的简短背景与有来源的分析仍然保留。专题功能留待单独设计。

## 实现与验证边界

`backend/daily_news/editorial.py` 保存共用写作规则及核查规则。初稿、英文翻译修复、时长编辑和事实核查改稿使用同一套写作要求。证据包与 Web 核查输入显式提供来源语言。

程序按新闻段落检查报道媒体名称和主要中文来源的就近身份说明；生成阶段遗漏会重试，最终发布前检查仍会拦截不合格稿。语义问题，例如把某公司的观点误归给媒体、引用正文中的另一家中文评论媒体却遗漏其身份，由独立 Web 核查检查，不把名称正则匹配等同于事实核查完成。

运行相关回归测试：

```sh
source .venv/bin/activate
python -m pytest backend/tests/test_daily_news.py backend/tests/test_daily_news_editorial.py backend/tests/test_news_source_expansion.py -q
```

真实模型预览保存在忽略的 `outputs/` 目录。使用历史证据包生成的预览仅验证文风与生成链路；正式播出仍须执行现有实时新闻核查与后续媒体验证。
