## 最有影响的结论

**这条样本的核心是大量、短时、语义对应的静态手绘插画，加连续旁白和硬切。生成动画不是复现这种观感的前提。** 视觉上也不只是白底黑色火柴人，而是暖纸张、少量低饱和色块和黑色不规则描边构成的插画故事板。

完整媒体的近静态检测结果如下：

| 检测条件 | 闭合近静态区间 | 累计时间 | 区间时长中位数 | 最长区间 |
| --- | ---: | ---: | ---: | ---: |
| 缩到 320 px 宽，`freezedetect=n=-45dB:d=0.5` | 306 | 900.567 秒 | 2.867 秒 | 6.833 秒 |
| 相同尺寸，更严格的 `n=-60dB` | 307 | 900.167 秒 | 2.867 秒 | 6.833 秒 |

最后一个区间约从 900.567 秒持续至片尾，未计入上述闭合区间总时长。检测会受压缩噪声、缩放和阈值影响，它衡量的是像素近似静止，不能识别创作者采用了什么工具，也不能直接当作人工逐镜头统计。但两个阈值及全片抽帧都支持：该样本几乎全是静态画面，常见每张约 2—4 秒，以硬切更新画意；没有看到需要连续角色动画才能完成的段落。置信度：高。

按约 3 秒一图粗估，同等密度的 15 分钟视频需要约 300 张画面。这是需要在产品中明确表现的生产规模；一张图撑一整段 20—30 秒旁白会明显失去该样本的节奏。可以提供较低图量的慢节奏预设，但应把它当成用户选择。

## 视觉语言

**画材和轮廓。** 奶油色纸张底、浅颗粒、边缘不完全规则的色块和略有抖动的深色线条。少量场景有室内透视、桌椅和窗户，但整体不追求写实光照。纸纹服务于统一观感，不应盖住轮廓与文字。

**人物。** 圆或椭圆头、细长肢体、简化手脚；有时是纯线条身体，有时穿单色色块衣服。脸可留白，也可用两点眼睛、眉线和小嘴表达困惑、疲劳、得意。不同镜头人物、肤色和服装会变化，并非必须追踪一个固定主角。若本项目希望建立频道识别度，可以另加固定主角设定；这是产品微调，不是样本已有的严格角色规则。

**色彩。** 主要是奶油白、灰蓝、橄榄绿、陶土橙、芥末黄、暖棕。常见天空/墙壁与地面两三个横向色块。这里没有从视频反推出精确品牌色；实现中应使用可修改色板，而不要把取样色值声称为频道官方规范。

**构图。** 一幅画尽量只承担一个概念。人物全景、桌面特写、符号牌、物体比喻和简图交替出现。留白充足，主要内容通常集中于画面中部；顶部留给少量关键词和数字。背景密度有变化，但很少同时让多个物体争夺注意力。

**文字。** 画内是少量手写感的大写英文或数字，没有常驻长段落。下载媒体没有浏览器截图中的底部黑框英文；那是 YouTube 可开关 CC。生成流程应分开“画内关键词”和“旁白字幕”，不要误把播放器字幕当成原片烧录风格。建议关键词由渲染器加字，图像提示词要求预留空白，避免让生成模型负责精确拼写。

**运动和转场。** 该样本的时间感来自切图、姿态和画内动作符号，通常不需要推拉镜头、视差、转场特效或连续口型。静态图片里的奔跑、抛球和运动线不等于视频动画。默认可以关闭镜头运动；用户想增加动态时，再允许少数图片经 Gemini 生成短片。

## 脚本、节奏与音画对应

英语原始自动字幕约 2,811 词，除以媒体时长约为 187 词/分钟。这个值是自动字幕估计，不是声学字词对齐结果。口播组织密度较高，画面时常在一句话内部换图：新对象、比较、因果关系或关键数字出现时切换，而不是机械地每个句号换图。约 3 秒的图片区间与这种信息密度相配。

结构上，约 00:00—01:30 建立收益预期和反常识矛盾，约 01:30—06:30 解释模型、常见误区与研究背景，约 06:30—12:45 展开五条方法，之后回扣机制并提出行动和互动。它先用日常问题吸引注意，再用研究名、人名和年份增加依据感。这个组织结构值得参考，但不必照搬约六分半才进入方法清单的铺垫长度。

本项目可保留“具体问题 → 解释机制 → 例子或证据 → 可做的动作”，按用户提供的调研材料生成原创长脚本。基于用户对证据、机制和实际可用性的偏好，建议减少无法从资料证明的绝对承诺，优先使用清楚的因果图、数量对比和可观察例子；风格上保持轻松，事实强度不随语气增强。

对音画一致性，最重要的单位是带有原文范围的叙事片段。每个镜头应保存所对应的旁白、句子范围、视觉意图和时长；旁白中的对象、动作和数量必须在该镜头或明确延续的上下文中出现。先生成并量取真实语音时长，再把同一段的若干镜头分配到这个时长内。不要靠统一“每图五秒”去拼整段 TTS，也不要只按脚本字数估算最终音轨长度。

本次不对嗓音性别、TTS 供应商、背景音乐或混音音量作确定判断；未进行专门听音和声源分离。可以确认媒体有英文音轨，字幕和视觉足以支持上述节奏与结构分析。

## 可参数化风格建议

以下是实现建议，不是当前代码能力的声明。配置应保存到作品，渲染时使用该版本，保证后续修改默认值不会改变已经生成的作品。

| 参数 | 参考预设建议 | 保留的调整空间 |
| --- | --- | --- |
| 画面风格描述 | 暖纸张、细黑手绘线、圆头简化人物、有限色块 | 自定义提示词和禁止元素 |
| 色板 | 奶油、灰蓝、橄榄绿、陶土橙、芥末黄 | 用户覆盖色值及主辅色 |
| 角色说明 | 简化人物，可选表情，不要求写实 | 固定主角、服饰、肤色、参考图 |
| 镜头目标时长 | 约 3 秒；允许随语义在 2—6 秒间调整 | 更慢的低图量模式 |
| 默认运动 | 静态 | 轻推拉、局部动画、Gemini 图生视频 |
| 默认转场 | 硬切 | 简单淡入淡出，时长可调 |
| 生成视频比例 | 0；由用户选定需要动态的镜头 | 每镜头显式开关或比例上限 |
| 画内文字 | 稀疏关键词，建议每镜头 0—4 词 | 字体、字号、位置、语言 |
| 旁白字幕 | 可选，独立于画内文字 | 关闭、整句、短句；样式可调 |
| 英文语速 | 约 165—185 词/分钟起步 | 按声音和目标观众调整；最终以实测音轨为准 |
| 背景密度 | 低到中，一个明确视觉焦点 | 极简、少量环境、完整插画 |

生成画面可采用这种通用提示词骨架，由每个镜头填入自己的视觉意图：

> Warm cream paper background with subtle grain. Uneven dark hand-drawn outlines, simple round-headed figures with thin limbs, restrained muted blue, olive, terracotta and mustard color blocks. One clear visual metaphor: {visual_intent}. Scene objects and action: {objects_and_action}. Wide composition, generous negative space, minimal facial marks, consistent illustration language. Leave the upper safe area clear for later text overlay. No rendered lettering, no photorealism, no glossy 3D shading, no busy decorative elements. Character reference: {character_notes}.

若选择图生视频，运动指令应绑定当前镜头，例如只轻微抬手、移动一个物体或缓慢推近，保持人物比例、道具数量和色板；一个镜头只做一个动作。动态片的可用时长、首尾状态和旁白边界需要检查，不能因“生成成功”就假设它能自动无缝拼接。

## 对独立功能的流程建议

新入口可以是“图解工作室”或“长视频工作室”。用户输入调研材料、主题和表达偏好，先获得可编辑的长脚本；用户也可以直接粘贴自己的脚本。脚本是独立保存的中间产物，进入渲染之前可以修改。无需把自动选题、新闻抓取、公共素材下载或新闻审核接进这条路径。

脚本之后的最短路径是：脚本分段与镜头表 → 逐段 TTS 并测量时长 → 图像生成 → 对用户选择的镜头执行图生视频 → 按真实音轨对齐并合成 → 输出可播放文件。保留可恢复的镜头产物，重试失败镜头时不重新支付已成功镜头的成本。技术性校验应关注缺图、坏文件、时长、音画映射、媒体可播放性；这些是完成生成所需的验证，不是额外的新闻内容审核流程。

本调研没有仅凭画面推断频道的实际生成工具。GPT 文生图、OpenCLI、Gemini、TTS 和现有渲染器都是本项目可选择的实现机制；是否连通、是否部署、是否完成最终成片，需要独立验证。
